# Windows Opera — Atualizações

Aqui ficam as atualizações do Windows Opera. O **Windows Opera Update** consulta este
repositório sozinho e avisa quando há uma versão nova.

| Versão | O que mudou |
|---|---|
| 1.5 | Windows Media Player, WordPad, Painel de Entrada de Expressões Matemáticas, Mahjong, Agendador de Tarefas e tela azul de verdade |
| 1.4 | Windows Opera Update online, tela "Trabalhando nas atualizações", Bloco de Notas, Calculadora, Paint, Fotos, Editor do Registro, Informações do Sistema, Ferramenta de Captura e Campo Minado |
| 1.3 | Configurações, temas, Acesso rápido, Gerenciador de Tarefas e muito mais |
