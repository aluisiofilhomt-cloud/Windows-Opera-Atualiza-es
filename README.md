# Windows Opera — Atualizações

Aqui ficam as atualizações do Windows Opera. O **Windows Opera Update** consulta este
repositório sozinho e avisa quando há uma versão nova.

## 💿 Instalar do zero (sistema completo)

Quer o Windows Opera inteiro para instalar numa máquina virtual ou num PC?
Baixe o **ISO completo da versão 1.8** (dividido em partes por causa do limite do GitHub):

➡️ **[Partes do ISO + como juntar](../../tree/sistema-1.8/sistema)** — leia o `JUNTAR.md` dessa pasta.

As atualizações do dia a dia continuam pequenas e automáticas (pelo Windows Opera Update); este ISO é só para instalar do zero.

| Versão | O que mudou |
|---|---|
| 1.8 | Modo Escuro, protetores de tela clássicos (Tubos 3D, Texto 3D, Bolhas, Mystify), esquemas de sons, Ferramenta de Diagnóstico do DirectX (dxdiag) e Opções de Recuperação ("Escolha uma opção") |
| 1.7 | Email, Contatos, Calendário com lembretes, impressora "Microsoft Print to PDF" e Editor de Política de Grupo |
| 1.6 | Movie Maker, Windows Journal, PowerShell, menu Win+X, pastas .zip, Opções de Energia, Mouse, Teclado, Resolução da Tela, Dispositivos e Impressoras, Conexões de Rede, Fax e Scanner, Firewall, Ferramenta de Remoção de Software Mal-Intencionado e Solução de Problemas |
| 1.5 | Windows Media Player, WordPad, Painel de Entrada de Expressões Matemáticas, Mahjong, Agendador de Tarefas e tela azul de verdade |
| 1.4 | Windows Opera Update online, tela "Trabalhando nas atualizações", Bloco de Notas, Calculadora, Paint, Fotos, Editor do Registro, Informações do Sistema, Ferramenta de Captura e Campo Minado |
| 1.3 | Configurações, temas, Acesso rápido, Gerenciador de Tarefas e muito mais |
